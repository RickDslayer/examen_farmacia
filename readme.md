introduccion:
es un programa que permite el registro (id,nombre,direccion,telefono,id del gerente), edicion, eliminacion y listado de sucursales en un archivo json y listado filtrado por nombre

manual de uso:
por medio del menu puede darle a las opciones segun lo que necesite el usuario
opcion 1: registro de sucursal = le pedira al usuarios los datos de la sucursal a registrar y revisara que no exista una sucursal con la misma ID
opcion 2: editar sucursal = le pedira al usuario cual es la id de la sucursal a editar y despues pedira los nuevos campos que se editaran 
opcion 3: eliminar sucursal = le pedira al usuario cual es la id de la terminal a eliminar
opcion 4: le listara al usuario todas las terminales existentes
opcion 5: le pedira al usuario el nombre de la sucursal que desea buscar y listara todas las sucursales con ese nombre

estructura de trabajo:
se trabajo principalmente todos los cambios en la rama de desarrollo y una vez estuvo lista una version funcional del proyecto se hizo merge a la rama main

resolucion de conflictos:
cada que habia que hacer un arreglo de alguna funcion que no trabajaba como debia se hacia un commit con el arreglo de dicha funcion
